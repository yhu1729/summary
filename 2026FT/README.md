### Summary

This paper develops an analytical design procedure for tailoring plasma density downramps in laser wake-field acceleration. The model starts from an improved fully relativistic plane description and links the initial cold plasma density to the laser pulse profile. The goal is to control partial wave breaking, trigger electron self-injection at the downramp, and increase the acceleration of small injected bunches during the early acceleration phase. The analysis yields a multi-step optimization workflow rather than only a numerical scan. Particle-in-cell simulations using the same input data are then used as an independent check, and the paper reports excellent agreement between the analytical predictions and simulated behavior. The result is a reduced-model tool for designing downramp injection stages before running expensive kinetic simulations. Its scope is deliberately early-stage acceleration in an idealized geometry, so the paper is best read as a controlled density-profile optimization method rather than a full accelerator-system design.

### Contributions

1. Built an analytical procedure for optimizing plasma density profiles for downramp injection.
2. Connected the density tailoring problem to a fully relativistic plane model of laser wake-field acceleration.
3. Targeted controlled partial wave breaking and self-injection of small electron bunches.
4. Compared the optimized profiles against particle-in-cell simulations with matched inputs.
5. Provided a design workflow that can reduce reliance on brute-force kinetic parameter scans.
